Forensic Nexus
> AI-powered Digital Forensics & OSINT Toolkit for investigators, researchers, and security professionals.

Forensic Nexus is an open-source platform designed to simplify digital investigations by combining forensic analysis, evidence collection, and OSINT workflows into a single interface.
- Frontend: React / Next.js
- Backend: Python / FastAPI
- Database: PostgreSQL
- AI: OpenAI / Gemini / Ollama *(edit as needed)*

git clone https://github.com/arashx1/forensic-nexus.git

 Install dependencies

```bash
npm install
```

or

```bash
pip install -r requirements.txt
```


```bash
npm run dev
```

or

```bash
python app.py
```
